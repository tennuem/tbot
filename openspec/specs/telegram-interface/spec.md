# telegram-interface Specification

## Purpose
Предоставлять понятные команды и музыкальные ссылки в личных чатах и группах, корректно адресуя ответы нужному пользователю и боту.

## Requirements

### Requirement: Command routing
Бот SHALL поддерживать `/start`, `/help`, `/ping`, `/list` и `/chatid`, включая обращения с собственным `@username`, и игнорировать команды другим ботам.

#### Scenario: Group command
- **WHEN** пользователь отправляет `/help@имя_этого_бота`
- **THEN** бот возвращает подсказку, а `/help@имя_другого_бота` остаётся без ответа

#### Scenario: Start and unknown command
- **WHEN** пользователь отправляет `/start` или неизвестную команду этому боту
- **THEN** `/start` объясняет использование, а неизвестная команда предлагает `/help` без внутренней ошибки роутера

### Requirement: Honest ping metrics
Команда `/ping` SHALL показывать `pong`, время работы бота и приблизительное время с отправки сообщения при наличии его даты, не выдавая его за полный сетевой RTT.

#### Scenario: Ping contains a timestamp
- **WHEN** получена команда `/ping` с датой отправки
- **THEN** ответ указывает секундную точность оценки и аптайм бота

### Requirement: Personal list pages
Команда `/list` SHALL показывать до 100 последних различных треков отправителя, включая его повторные отправки чужих ранее известных треков, и разбивать длинный ответ на страницы.

#### Scenario: Large personal history
- **WHEN** история пользователя не помещается в одно сообщение
- **THEN** ответ укладывается в лимит Telegram и предлагает следующую страницу через `/list N`

#### Scenario: Empty history
- **WHEN** у пользователя нет сохранённых треков
- **THEN** бот сообщает об этом понятным текстом

### Requirement: HTML service links
Ответ с треком SHALL использовать экранированный HTML, кликабельные названия других сервисов, отключённое превью и не содержать клавиатуру ссылок или служебную строку о кеше.

#### Scenario: Special characters in metadata
- **WHEN** название трека или имя отправителя содержит HTML-символы
- **THEN** они отображаются как текст и не изменяют разметку ответа

### Requirement: Optional service logos
Бот SHALL загружать custom emoji из настроенного пака при запуске, сопоставлять сервисы по назначенным emoji и использовать текстовые ссылки, если логотипы недоступны.

#### Scenario: Reordered emoji set
- **WHEN** порядок иконок изменён, но назначения emoji сохранены
- **THEN** логотипы остаются привязаны к соответствующим сервисам

#### Scenario: Missing set or icon
- **WHEN** загрузка пака не удалась или отдельная иконка отсутствует
- **THEN** соответствующие ссылки остаются обычными текстовыми ссылками
